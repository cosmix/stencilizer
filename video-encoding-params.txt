# 1. Lossless master (frames piped from the renderer)
ffmpeg -f rawvideo -pix_fmt bgra -s 1920x1080 -framerate 30 -i - \
  -c:v libx264 -preset ultrafast -qp 0 -pix_fmt yuv420p master_lossless.mp4

# 2. Final video encode
ffmpeg -i master_lossless.mp4 \
  -c:v libx264 -preset veryslow -crf 21 -pix_fmt yuv420p video.mp4

# 3. Add the soundtrack (48 kHz stereo WAV)
ffmpeg -i video.mp4 -i soundtrack.wav \
  -c:v copy -c:a aac -b:a 160k -shortest -movflags +faststart stencilizer-intro.mp4

Steps 1 and 2 can be combined: pipe the frames straight into the step 2 settings. With the render script that's ENC_ARGS="-c:v libx264 -preset veryslow -crf 21".

Output streams:
- Video: H.264 High profile, level 5.1, 1920×1080, 30 fps, 8-bit 4:2:0, about 4.7 Mb/s.
- Audio: AAC-LC, 48 kHz stereo, about 176 kb/s.

Full x264 options:

cabac=1 ref=16 deblock=1:0:0 analyse=0x3:0x133 me=umh subme=10 psy=1 psy_rd=1.00:0.00
mixed_ref=1 me_range=24 chroma_me=1 trellis=2 8x8dct=1 cqm=0 deadzone=21,11 fast_pskip=1
chroma_qp_offset=-2 threads=34 lookahead_threads=5 sliced_threads=0 nr=0 decimate=1
interlaced=0 bluray_compat=0 constrained_intra=0 bframes=8 b_pyramid=2 b_adapt=2 b_bias=0
direct=3 weightb=1 open_gop=0 weightp=2 keyint=250 keyint_min=25 scenecut=40
intra_refresh=0 rc_lookahead=60 rc=crf mbtree=1 crf=21.0 qcomp=0.60 qpmin=0 qpmax=69
qpstep=4 ip_ratio=1.40 aq=1:1.00

threads=34 comes from this machine's core count and doesn't affect the output.

One compatibility note: veryslow's ref=16 pushes the file to H.264 level 5.1. Browsers and current phones play that fine, but some older hardware players cap out at level 4.1. If you ever need one of those, add -level 4.1 to step 2 (x264 then limits its reference frames to fit), at a small size cost.
