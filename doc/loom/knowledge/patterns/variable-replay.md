# Variable Replay

> Variable replay, width scaling, validation, delta solve, measured rates

## Replay pipeline

`variable/transform.py` `transform_variable_glyph(vg, bridge, geometry, upm)` stencils one `VariableGlyph` (default `Glyph`, `Support` regions, one full master `Glyph` per support; `variable/model.py`). Steps, each of which can end in an unchanged glyph whose default islands are counted as unbridged:

1. `flatten_compatible` (flatten.py): every master becomes a polygon with one structure; a curve needing more than `MAX_SUBDIVISIONS = 64` pieces raises `VariationDataError`.
2. `remove_overlaps_compatible` (overlaps.py): skia-pathops merges overlaps once on the default, every output vertex is mapped back to an input vertex or the crossing of two input edges, and the map is replayed on each master. Returns None when it cannot.
3. Default surgery: core `GlyphTransformer.transform_with_outcome` on the merged default; zero bridges ends the pipeline as a no-op.
4. `map_surgery(merged.default, outcome.glyph, snap)` (replay.py) records the source of every output point and groups bridge-line points into `BridgeLine`s; `align_to_lines` (align.py) puts every line point exactly on its line in the default; `replay` rebuilds the glyph per master.
5. `round_variable_glyph` (rounding.py) rounds to what the target format stores; `validate` (validate.py) checks the rounded glyph.

Steps 3-5 are one attempt, `transform._bridged(step=...)`; `transform._first_bridged` repeats it down the width fallback chain ("Width scaling") and the first attempt that replays and validates wins.

`VariationDataError` (singular supports, incompatible masters, unsupported CFF2 `vsindex`) never escapes a glyph: the glyph is written unchanged and counted. `process_variable_glyph` is the picklable worker wrapper; `variable/processing.py` is the `FontProcessor` hook (classification, selection, save) and `core/pool.py` spawns the workers.

## Bridge-line grouping and realignment

Cross-master replay must keep every point of one bridge line on one axis-aligned line in each master. Fixed edge parameters do not (mistakes.md "Fixed-parameter replay breaks bridge-cut coincidence across masters").

- A cut point's line axis comes from its surgery-created output segment (both ends not on one input edge; mostly vertical means an x line); the source-edge axis is the fallback. The edge-axis rule alone put cuts on steep slanted edges on y lines.
- An output vertex that ends a surgery segment joins the nearest same-axis line within `snap_distance(geometry, upm)` (the core's contour gap or point dedup tolerance, scaled by UPM) and sits exactly on it in the default and every master. Core surgery keeps an input vertex in place of a cut point within `bridge_tolerance` of the line (`core/bridge_segments.py:78-100`), which left one cut edge leaning off its line; `align.py` fixes that on the default before replay, and a fixed 0.5-unit snap missed 2048-UPM fonts where offsets reach 0.8.
- `LineMember` carries no offset; `map_surgery` keeps its default `_SNAP_DISTANCE = 0.5` for callers that pass none.
- Module layering: `variable/realign.py` is the bottom module (`contour_spans`, `axis_value`, `lerp`, `mean_target`, `realign_line`, `project`, `_crossing`, `_SEARCH_EDGES = 12`, `Extent`, `Span`, `Placed`, `extents_overlap`). `bridge_width.py` imports it at runtime, `replay.py` imports both, and `realign.py` and `bridge_width.py` name `BridgeLine`, `SurgeryMap`, `Slot` and `LineMember` from `replay.py` only under `TYPE_CHECKING`. A runtime import of `replay.py` from either would be a cycle, because `replay()` must call `bridge_width.pair_targets`.
- Per master, `replay()` (replay.py:308) puts each cut point at its default edge parameter (`_place`) and computes every line's mean target (`realign.mean_target`). When `SurgeryMap.widths` (a `bridge_width.WidthRule`) is set, `bridge_width.pair_targets` replaces the targets of every disjoint pair of lines by the pair's centre -/+ half a gap (see "Width scaling"); lines left unpaired keep their mean. `realign.realign_line` then moves each member onto the nearest crossing of its edge with the target (`realign._crossing`, up to `_SEARCH_EDGES = 12` edges away) and `realign.project` snaps wrong-side neighbours, never moving the line points and cut points in `_stops`.
- The default master is not resized. `align_to_lines` (align.py) puts each line point on its line's mean target on a widthless map, so the default output is identical in both width modes and to the output with no width rule.
- Overlap-union crossings slide along flattened curves from master to master and may pass neighbouring union vertices, which folds the outline into spikes, bow-ties and sliver holes. `variable/crossings.py` collapses those vertices onto a re-intersected crossing. `overlaps.py` accepts crossings past their edge ends (only parallel edges and flipped orientation return None), because a stricter on-segment check rejected Inter A/R/e/x and 14 Cantarell glyphs.
- The overlap result is rejected when XOR area against its own pathops union exceeds `FIDELITY_RELATIVE = 3%` of the union plus `FIDELITY_FLOOR = 1` unit squared (overlaps.py:38-39, 192). Measured: legitimate sliding merges deviate up to 1.92% (Cantarell `a`), a pulled-apart box pair 37%. Slivers up to about 5 units wide are accepted.

## Validation

`validate(vg, upm, allowed_islands, lines=())` runs on the rounded glyph at `validation_locations`: the default, every support peak and a grid over the used axis values (full product up to `MAX_GRID_LOCATIONS = 64`, otherwise each axis end alone plus the all-minimum and all-maximum corners). At each location it requires the analyzer island count and `holes.enclosed_counters` (skia-pathops non-zero union, pinch points split, both contour directions) to stay at or under `allowed_islands`, and `_bridges_intact`. `GlyphAnalyzer` misses counters closed by a bow-tie or a hairline wall, and pathops resolves near-coincident tangles differently by contour direction and treats a hole touching the outer contour at one point inconsistently, hence the both-direction max. `lines` is optional; line order is compared only between same-axis lines whose cut points overlap on the other axis, since bridges of different counters (an `8`) legitimately cross.

## Delta solve and rounding

`solver.solve_deltas` solves `M . D = masters - default` with `M[j][k] = supports[k].scalar(peak_j)` against the ORIGINAL supports, by Gauss-Jordan; a pivot at or under 1e-12 raises `VariationDataError("singular variation supports")`. Solving master minus default independently is wrong where regions overlap. `round_variable_glyph` stores an integer default and integer deltas chosen so each peak lands within 0.5 of the exact outline (`_round_deltas`, the gvar algorithm), for CFF2 as well: fontTools' CFF2 instancer rounds every blended relative operand, so fractional deltas make coincident edges on separate contours drift apart. `write_cff2` re-solves deltas from the rebuilt masters and snaps them with `round_coords` because solver noise (about 1e-13) defeats the operand's zero-delta check. Glyphs the engine leaves alone keep their original glyf/gvar data or charstring byte for byte; a source glyph can already hold half-integer CFF2 blends (Cantarell `four`).

## Measured outcomes

**System fonts.** Full fonts, all validation locations, rounded (before width scaling): Ubuntu[wdth,wght] 209 of 229 island glyphs bridged (6 no static bridge, 13 replay finds no crossing, 1 unmappable); InterVariable 248 of 283 (24 no crossing, 7 rejected by line order or piece orientation, 2 unmappable, 1 island, 1 no static bridge); Cantarell-VF 394 of 413 (13 no static bridge, 6 no crossing). "No crossing" glyphs have counters that close or narrow below the bridge width in a bold or condensed master (oe, percent.osf, registered, superscripts); leaving them unbridged is correct.

**Fixtures** (`tests/fixtures/variable/`, default `BridgeConfig()`, auto direction). The CLI report is 21 glyphs / 28 bridges / 2 unbridged for Inter and 21 / 22 / 2 for Ubuntu and Cantarell, in both modes (`ampersand` is unbridged in every fixture). Island glyphs bridged, by the fallback step that won:

| Fixture | Fixed mode | Proportional mode |
| --- | --- | --- |
| Inter | 20 of 21: 19 fixed, `e` mean | 20 of 21: 18 proportional, `a` fixed, `e` mean |
| Ubuntu | 20 of 21: all fixed | 20 of 21: 15 proportional, 5 fixed (`a e o zero eight`) |
| Cantarell | 20 of 21: all fixed | 20 of 21: 18 proportional, 2 fixed (`a e`) |

With horizontal direction Inter bridges 21 (fixed: 19 at fixed, 2 at mean: `e`, `ampersand`), Ubuntu 19 (`ampersand` and `B` unchanged), Cantarell 21 (fixed all; proportional 17 proportional and 4 fixed). `test_fixture_glyphs_keep_baseline_outcome` pins the per-glyph `bridge_count/unbridged_count` of the pre-scaling code in both modes. Defaults are identical between modes and to the output before width scaling; the masters changed for 18, 19 and 20 glyphs. Inter `o` gaps at Thin / default / Black: before scaling 117 / 123 / 109 (opsz+Black 103), fixed 123 / 123 / 123 (opsz 122), proportional 61 / 123 / 231 (opsz+Black 241), stroke ratios 0.270 and 1.881. Proportional output equals fixed output at every peak for Inter `a`, Ubuntu `a e eight o zero` and Cantarell `a e` (whole-glyph fallback to the fixed gap; concerns.md "Width-scaling fallbacks are unreported"). Stenciled fixtures keep 0 islands and 0 enclosed counters at every peak except `ampersand`.

**Cost.** Worst cold GUI preview over the fixture island glyphs (`test_cold_preview_time_per_island_glyph`, Inter) is about 24 ms (23.3 ms before width scaling); a failing proportional glyph runs up to three attempts, at most 15% more per glyph.

## Checking output

- `GlyphAnalyzer` uses exact float comparisons (core/analyzer.py:247 strict bbox nesting, :273 `a*b <= 0`), so fontTools runtime-evaluated CFF2 instances with 5e-13 noise show false islands at some weights, and `island_count` on stenciled Cantarell `o` reports 1 at off-grid weights (150, 250, 275, 300) where `enclosed_counters` reports 0. The pipeline validates on `vg.instance`, so output is unaffected; external sweeps must snap coordinates or use `enclosed_counters`.
- `instantiateVariableFont` on stenciled CFF2 output drifts bridge-line points apart by up to about 10 units at intermediate weights (wght 170) and closes counters in `o`, `B`, `D`. Integer deltas make masters and axis extremes exact; the drift between them is inherent to the fontTools CFF2 instancer. gvar fonts instantiate cleanly.
- Tests that monkeypatch names imported into `variable.transform` (`replay`, `validate`, `map_surgery`) take the real function from its defining module; reading it back as `transform.replay` fails mypy `attr-defined`. A `replay()` that returns None through tied vertices needs ties inside one input contour; `_resolve` drops ties across contours (replay.py:157-160).

## Width scaling

`BridgeConfig` (config/settings.py:112-127) carries `width_scaling` (`BridgeWidthScaling.FIXED` default, or `PROPORTIONAL`), `scaling_strength` (0-100, default 100) and `min_width_percent` (10-110, default 30). Static fonts ignore all three: `width_percent` alone sizes their bridges. `variable/bridge_width.py` owns the rules; `transform._bridged` builds a `WidthRule` per attempt and stores it in `SurgeryMap.widths`.

- **Formula** (`scaled_gap`). Fixed: `gap = base`, the pair's gap in the default output. Proportional: `gap = max(minimum, base * ratio ** (strength / 100))` with `minimum = min(min_width_percent / 100 * REFERENCE_STROKE_FRACTION * upm, base)`, so the minimum never exceeds the default gap. `REFERENCE_STROKE_FRACTION` (config/settings.py) is the one 10%-of-UPM constant; `core/surgery.py` and `bridge_width.py` import it. There is no upper bound: a large ratio can overshoot a counter, and only `validate` and the fallback chain stop it.
- **Fixed mode** is exact up to integer rounding: Inter `o` has a gap of 123 at Thin, default and Black and 122 at the opsz master (base 122.88).
- **Pairing** (`disjoint_pairs`). Sort the lines by (axis, default coordinate). Walking upward, pair each unpaired line with the nearest unpaired line above it that has the same input-contour set (`contour_spans` of the merged default) and an overlapping cross-axis span in the default output. Leftover lines keep their mean target. Nearest distance alone fails (Inter `.notdef` lines 941.44 and 946.56 belong to different bridges); `validate._facing_pairs` pairs every overlapping same-axis couple (91 pairs for 14 lines of `.notdef`) and stays the validation rule only. A spanning `eight` pairs on `{0,143,216}`; Inter `eight` with horizontal direction has no spanning bridge (2 horizontal bridges, 4 lines, 2 pairs of 122.88) and gets one only under AUTO.
- **Centre and extent** (`pair_targets`). A pair's centre in a master is the mean of its two lines' mean targets at the fixed edge parameters; its extent is the min..max cross-axis coordinate of the two lines' placed points in that master. The default's extent applied to a wider master under-measures it (Inter `o` horizontal at Black: ratio 1.884 against 2.261).
- **Ink** (`ink`). Cross the centre line with every edge of the master's merged (flattened, overlap-removed) polygon, half-open so an edge on the line is skipped, sort the crossings, pair them even-odd and clip each interval to the extent, then sum. Filtering crossings to the extent before pairing measures the counter on round glyphs (Inter `o`: 833.9 instead of about 316). `zip(strict=True)` on the pairs is an invariant of closed polygons.
- **Ratio** (`stroke_ratio`). Master ink over default ink; a default ink of 0 gives 1; a master ink of 0 gives 0, and `0.0 ** 0.0 == 1`, so strength 0 gives `base` and any other strength gives the minimum.
- **Placement.** The pair's line with the lower default coordinate goes to `centre - gap / 2`, the other to `centre + gap / 2`, which keeps the order `validate._bridges_intact` checks. Crossing search and projection then run against those targets.
- **Fallback chain** (`fallback_steps`, `transform._first_bridged`). Configured mode, then fixed, then per-line mean targets with no pairing (`step=None`); fixed mode has only the last two. `_bridged` is one attempt and a replay failure or a validation failure both move to the next step. The first step that bridges wins, so a glyph only proportional mode can bridge stays bridged (a ring whose counter is narrower than the fixed gap), and a glyph falls back as a whole, not per master. When all steps fail the glyph is unchanged and its islands are counted.
- **Why per-bridge ratios.** Axis values do not map to stroke width (`wght` 700 is no width, and `opsz` changes thickness in either direction by font), and one font-wide ratio per location misses glyphs whose strokes change differently. Each bridge measures the stroke it cuts.
- **`--instance`, glyf fonts, proportional.** `cli/app.py` `_run_stencil_first`: `validate_instance`, stencil the variable font into a temporary `<stem>-variable<suffix>`, then `handlers.stencil_pinned`: `pinning.pin_stenciled` swaps the source font's `name` table into the stenciled font (so the instancer and writer yield names such as "Inter Variable Text Black Stenciled") and pins it with `instantiate_static`; a static `FontProcessor` with `fixed_width_settings` then stencils the glyphs the variable run left with islands (`ampersand` on Inter wght=900 and Ubuntu wght=600), or `publish_pinned` only renames when none are left. The report uses the wall clock from before pass 1 to after pass 2, bridges summed and the unbridged count of pass 2. `--list-islands` and `--dry-run` pin first in every mode. Stencil then pin keeps counters open on gvar fonts (0 enclosed counters at Inter 150/550/750 and Ubuntu 350/550 except `ampersand`).
- **`--instance`, CFF2 fonts pin first.** `handlers.resolve_width_scaling` prints `CFF2_WARNING` (unless `--quiet`) and switches to fixed, because the fontTools CFF2 instancer moves bridge-line points between masters ("Checking output"): stencil then pin left 17 of 21 Cantarell island glyphs with closed counters at wght 170, 250 and 600 (18 at 700) against 1-2 for pin first, and a static second pass still left 13. A static font with proportional gets `STATIC_WARNING` and fixed; the check reads the input file, never the pinned temporary one, so a static `--instance` still fails with "--instance requires a variable font".

## Testing width scaling

- `tests/unit/test_width_scaling.py` `test_fixture_glyphs_keep_baseline_outcome` pins every fixture glyph's `bridge_count/unbridged_count` in both modes; the engine tests share the Inter `B`, `eight`, `o` and `.notdef` pairing cases.
- A proportional `--instance` run on Inter bridges every island in pass 1, so pass 2 only publishes: a test that needs a real pass-2 glyph failure fakes pass 1 with a copy of the unstenciled font (`tests/unit/test_cli_width_scaling.py`). Real run: Inter `--instance wght=900` proportional gives 30 bridges (28 from pass 1, `ampersand` from pass 2) and name ID 1 "Inter Variable Text Black Stenciled"; Cantarell `--instance wght=250` prints the CFF2 warning and equals the fixed run in all 24 glyphs.
- Pin-first with fixed width is the weaker flow on gvar fonts: Inter `--instance wght=550` leaves `a` with one enclosed counter, which stencil-first closes; contract `cli-instance-proportional-open-off-master` encodes it.
- `--instance` output of a CFF2 font carries glyph names `cid000NN`, and the CFF2 warning wraps at 80 columns in non-tty output, so substring assertions flatten whitespace first.
