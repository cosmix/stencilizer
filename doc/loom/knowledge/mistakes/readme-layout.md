# Readme Layout

> Place README screenshots beside the content they illustrate

## Separate README visuals by purpose

**What happened:** Placed the GUI screenshot directly after the existing comparison image, creating an awkward stack of large visuals. The user flagged the layout.

**Why:** Chose prominent placement without considering the existing visual hierarchy.

**Prevention:** Review surrounding content before inserting images; place screenshots alongside the section they illustrate.

**Fix:** Move the GUI screenshot and caption into the Graphical Interface usage section.
