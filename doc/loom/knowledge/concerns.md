# Concerns & Technical Debt

> Technical debt, warnings, issues, and improvements needed.
> Lists only extant issues: delete an entry once it is fixed.

## Unknown config fields are silently ignored

`BridgeConfig` and `GeometryConfig` (src/stencilizer/config/settings.py) use pydantic's default `extra="ignore"`, so a removed or misspelled field such as `BridgeConfig(min_bridges=1)` is accepted and has no effect.

## Ignored `process_glyph` parameter

`process_glyph` (src/stencilizer/core/processor.py) still accepts a fourth `reference_stroke_width` parameter and ignores it, because the regression helpers in tests/regression/_golden.py pass it positionally. Drop it together with that call site.

## Native-UPM output change not visually reviewed

UPM scaling made fonts not at 1000 UPM behave as the 1000-UPM tuning scaled. For Roboto (2048) and Lato (2000), 75 of 1009 island glyphs changed output (17 gained contours, 5 lost contours, 53 kept the count). The changes are intended but nobody has inspected the rendered glyphs.

## Unchecked classification reuse

A caller-supplied `classification` passed to `FontProcessor.process` is used without checking it came from the file `process` reopens (core/processor.py:226), so an edited source mixes old outlines with new tables; only the GUI guards this, with its source digest check (architecture/gui.md "Save safety"). Tests of a save must read the output back rather than trust the stats. A failed `writer.update_glyph` in `_save_font` raises `FontSaveError` and publishes nothing (core/processor.py:349-355).

## Composite glyphs read without contours

`fonttools_glyph_to_domain` (io/converter.py) records only outline segments, so a composite glyph (Roboto `Aacute` = `A` + `acute`) has zero contours and `classify_glyphs` files it as "empty glyph". The converter reads `fonttools_glyph._glyph`, which fontTools' `_TTGlyphGlyf` glyph-set objects lack, so `Glyph.is_composite()` is always False and `ProcessingConfig.skip_composite` never fires (dead setting). The saved font still bridges composites through the glyph they reference. The GUI does not depend on the reader: `gui/composites.py` resolves composites from the fontTools glyph set and `FontSession.display_glyphs` lists them (architecture/gui.md "Composites in the grid"); the core and CLI still see them as empty. The variable path skips composites with reason "composite glyph" and ignores `skip_composite` on purpose; a variable GUI session previews a composite at the default axis location only. Component `hmtx` lsb is not moved when a referenced glyph's `xMin` changes (concern "Variable fonts: known gaps").

## CommitMono .notdef renders as a solid box

Under Auto, CommitMono `.notdef` (frame, hole, inverted "404" digits) stencils into overlapping full-width outer rectangles, so preview and saved glyph render as a solid black box (24 output contours). The defect is in the inverted-island path (`core/surgery_nested.py`) and is outside the direction work because Auto output is pinned. The transformer reports 5 bridges and 0 unbridged islands, so the glyph no longer shows in the unbridged warning, while `GlyphAnalyzer` counts 6 islands in the output. The bridged counter pieces touch their own piece and the analyzer files them under the stray rectangles; the render shows one enclosed sliver. Repro: `process_glyph` on that glyph with `BridgeConfig()`. Which real glyphs reach `_process_inverted` is unknown; the synthetic filled encircled digit never does (patterns/bridge-algorithm.md).

## Full test suite near the acceptance time cap

`uv run pytest --no-cov -q -p no:cacheprovider -n auto` ran 626 tests in 79 s (80 s wall, 32 workers) on the variable-fonts tree; pytest-xdist is a dev dependency (pyproject.toml:46). Without `-n` the suite was 366 tests in about 240 s before the variable work, against loom's 300 s limit per acceptance command, so an acceptance command that runs the whole suite needs `-n auto`. A test with a wall-clock bound flakes under xdist: `tests/gui/test_variable_session.py` `test_cold_preview_time_per_island_glyph` asserts a 5 s bound and prints timings.

The `window` fixture (`GuiController` plus `MainWindow`, tests/gui/conftest.py:143) is repeated across five `tests/gui` files and `_load_font` across three; one of them is the frozen `test_beautify_contracts.py`, which nothing may edit. Move both into `conftest.py` in a plan that owns those files.

## Sequential bridges cut through sibling counters

When an island group has no clear gap and no spanning bridge (`surgery_groups.arrangement` falls back to vertical, `_spanning` fails because the islands share no x range), `_sequential` (core/surgery_groups.py:108-135) bridges each island in turn, and every bridge band crosses the sibling counters of the same parent without splitting them. Holes are never obstructions (`geometry_crossings.is_bridge_path_clear`, core/geometry_crossings.py:112-119), `bridge_nested._nested_status` splits only the bridged island's own children, `SurgeryContext.merge` passes the original contours rather than the current pieces, and `_containing_piece` matches later islands by bbox centre, so a triangle whose centre lands in a gap is appended unchanged. Roboto `.notdef` (a box with four triangular counters, the first glyph the GUI previews for Roboto, tests/gui/test_main_window.py:66-78) comes out with 0 islands but stray holes crossing the bridge gaps, which render as black wedges. A prototype that splits overlapped sibling holes, restricted to siblings so nested rings (◎, ℗) are untouched, fixed `.notdef`, `naira`, `won`, `uni20BB`, `dollar`, `uni0E3F`, `uni2318` and `uni25A9`, and reduced glyphs with leftover islands or crossing contours from 69 to 59 in Roboto, 76 to 70 in Lato and 71 to 70 in CommitMono. Fixing it changes the static goldens, so it needs its own plan; the variable-font engine reuses this surgery on the default master and inherits the defect.

## Variable fonts: overlap-built counters

Many variable fonts keep overlapping contours, so a counter is formed by overlap rather than by a separate inner contour, and `GlyphAnalyzer` reports no island for the raw outline. Measured at the default master: Inter A D P R e 4 &, and Monaspace Neon A B D P R a b d e g p q 4 6 8 9 & @. The variable engine removes overlaps first (`variable/overlaps.py`), so those counters become islands before surgery; a glyph whose overlap merge fails (`remove_overlaps_compatible` returns None) stays unchanged and counts its flattened default's islands as unbridged. Island membership depends on winding and containment (`_classify_contours`, `_find_parents`, `_strictly_contains` in core/analyzer.py), which moving points can change, so the analyzer's answer at a non-default location can differ from the default's; `variable/holes.py` is the location-independent check ([patterns/variable-replay](patterns/variable-replay.md) "Validation").

## Static bridges can lean off the bridge line

`core/bridge_segments.build_contour_from_segments` (core/bridge_segments.py:99-111) skips the cut point when an input vertex lies within `bridge_tolerance` (the scaled contour gap) of the line, and `clean_points` (:115-124) drops a cut point within `point_tolerance` of the previous vertex, so one cut edge leans off the bridge line while its partner sits on it: Roboto `d` (282.67,602.7)→(823,602.44), Lato `o` (520.01,221.37)→(521,815.9), Cantarell `--instance wght=700` `g` (511,213.5)→(43.01,213.32). The counter stays enclosed by a hairline that touches the outside at one point at most, and per-point `otRound` at write widens it (213.5→214 against 213.32→213), so `GlyphAnalyzer` reports 0 islands for a glyph whose counter is still closed. A pinch-aware union count (`variable/holes.py`) finds 87 such outline glyphs in Roboto and 34 in Lato. Smallest fix: when a vertex stands in for a cut point, set its line-axis coordinate to the line (`axis.point(line, axis.cross(p), p.point_type)`); it changes the static goldens, so it needs its own plan. The variable path avoids it through `variable/align.py`.

## Variable fonts: known gaps

- **Composite lsb.** `write_gvar.py:99` moves `hmtx` lsb with `xMin` for the bridged glyph only. A composite that references it gets a header `xMin` recomputed by fontTools' glyf compile at save while its lsb stays, so FreeType translates the composite by the component's `xMin` change. It needs a bridge that cuts the leftmost extremum (font dependent) and also exists on the static TrueType path; `test_variable_writer_contracts.py:114-122` asserts only the advance.
- **Island allowance is an aggregate** (`variable/validate.py:136`): a master where the unbridged island vanishes while a bridged one reopens still totals `unbridged_count`. `_bridges_intact` mostly covers it; no failing glyph is known.
- **Support count is uncapped** (`variable/solver.py:32`): a gvar glyph can hold up to 4095 tuples, one master read per support and an O(n³) solve, and `VariableGlyph.instance` runs it on the GUI thread. A limit raising `VariationDataError` would bound it.
- **`fvar` with `CFF ` outlines** passes `gui/session.py` `unsupported_reason` and classification, runs the whole pool and fails at save ("unsupported variable outline format"); rejecting it early would save the run.
- **avar2** mappings are not applied when `gui/variable_session.py` normalizes slider locations (only `avar` segments).
- **CLI.** When only unsupported glyphs have islands, `cli/app.py` prints "No glyphs with islands found" and does not report them as unbridged; `variable_island_counts` (variable/processing.py:105) counts unsupported glyphs, so `--dry-run` and `--list-islands` include islands that are never bridged; the CLI has no input-equals-output guard (`FontSession.save` has one), now reachable with `--instance -o <input>`.
- **Stenciled CFF2 at intermediate weights.** `instantiateVariableFont` closes counters of stenciled Cantarell at non-peak weights; inherent to the fontTools CFF2 instancer ([patterns/variable-replay](patterns/variable-replay.md) "Checking output"), which is why proportional `--instance` pins first on CFF2 fonts.
- **`--instance` on a CFF2 font** yields a CID-keyed CFF with glyph names `cid00001…` (`cid000NN` in the output) and post format 3.0 (fontTools 4.66.0); an invalid `--instance` exits 1, not 2. `io/writer.py` `update_font_names` misplaces the suffix when the instancer leaves nameID 4 equal to the family. The CFF2 proportional warning wraps at 80 columns in non-tty output, so tests flatten whitespace before matching.
- **Replay edge cases without a known failing glyph:** `align_to_lines` (align.py:27) does not bound how far a default point moves (`realign._crossing` searches up to 12 edges); `_collect` (replay.py:209) can put one vertex slot into both an x and a y line; `crossings._behind` (crossings.py:89) compares raw displacement vectors and can over-collapse at walk depth 2 or more; `overlaps.py:219`'s fidelity tolerance is relative to the whole glyph area, so a localized distortion up to 3% passes. The fidelity check and `validate` reject the bad results, so the glyph stays unchanged.
- **Cost.** `variable/reader.py:93` builds a glyph set per support per glyph; `variable/processing.py` classifies every glyph serially in the main process and each selected glyph repeats flatten and overlap removal in its worker (`_counted_default` against `transform_variable_glyph`).

## Variable bridge gaps drift for mean-target glyphs

Fixed and proportional modes hold every bridge gap (Inter `o` is 123 at Thin, default and Black), but a glyph that reaches the third fallback step still places each bridge line at the mean of its cut points (`transform._bridged` with `step=None`, `variable/replay.py` `replay`), so its gaps drift as they did before width scaling (Inter `o` 117 / 123 / 109; a synthetic ring with a 60-unit default gap replayed at 50 bold and 75 thin). Measured on the fixtures: Inter `e` (both modes, and `ampersand` in horizontal direction) is the only glyph at that step; Ubuntu and Cantarell have none. The cure for such a glyph is a pairing or crossing-search fix that lets it pass an earlier step, not a change to the mean-target step ([patterns/variable-replay](patterns/variable-replay.md) "Width scaling").

## Width-scaling fallbacks are unreported

A glyph that falls back from proportional to fixed width, or from either to mean targets, is not reported in the CLI summary, in `ProcessingStats` or in the GUI: it counts as bridged and its output differs from what the user asked for. A glyph also falls back as a whole, so one master that fails sends all of them down the chain. Measured with `--width-scaling proportional` at strength 100 and the default minimum: Inter `a` (fixed gap) and `e` (mean targets); Ubuntu `a e o zero eight` (fixed gap), where `o` fails because its wdth -1 / wght 1 master's gap of 107.9 needs a crossing 16 edges away, past `realign._SEARCH_EDGES = 12`; Cantarell `a e` (fixed gap). These render identically to fixed mode at every peak. The proportional gap has no upper bound (`bridge_width.scaled_gap`), so a large ratio can overshoot a counter and only `validate` plus the chain reject it. Neither a per-master fallback nor a report was in the plan; a step counter in `VariableOutcome` surfaced through `ProcessingStats` and the GUI preview would give both, and a wider crossing search would recover `o`.

## Orchestration mistakes that recur without a hook

Two mistakes repeated across plans although each has a prevention rule. (1) A subagent ran `git stash` in a worktree shared with parallel engineers, once measuring a baseline ([mistakes.md "Subagent used git stash to measure a baseline"](mistakes.md)) and again to prove a GUI test fails on old code, which the subagent preamble's git restrictions did not stop. (2) `loom stage commit` was piped through `rg -o`, so the relay hook never saw the `LOOM_RELAY_V1` line and a staged file rode along in the next commit ([mistakes/review-and-completion-gates.md "Orchestration tool traps"](mistakes/review-and-completion-gates.md)). Proposals: a PreToolUse hook that rejects `git stash`, `git checkout --` and `git restore` in a subagent's Bash call inside a stage worktree, and one that rejects a `loom stage commit`, `loom memory` or `loom request` command followed by a pipe or redirect.
